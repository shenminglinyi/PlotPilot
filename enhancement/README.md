# PR5: 33维审计系统

## 解决的问题

现有审计维度太少（一致性、逻辑、伏笔等），很多质量问题发现不了。InkOS用33维审计，覆盖了从角色记忆到情感弧线的方方面面。

## 解决方案

将审计维度从6个扩展到33个，分为5大类：
- 角色维度（8个）
- 逻辑维度（6个）
- 叙事维度（7个）
- 文风维度（6个）
- 结构维度（6个）

## 文件结构

```
enhancement/
├── auditor_33dim.py      # 33维审计主程序
├── dimensions/           # 各维度检查器
│   ├── character.py      # 角色维度（8个）
│   ├── logic.py          # 逻辑维度（6个）
│   ├── narrative.py      # 叙事维度（7个）
│   ├── style.py          # 文风维度（6个）
│   └── structure.py      # 结构维度（6个）
├── score_calculator.py    # 综合评分计算
├── report_generator.py   # 审计报告生成
└── __init__.py
```

## 33维详细清单

### 角色维度（Character, 8个）

| # | 维度 | 检查内容 |
|---|------|---------|
| C1 | 角色记忆 | 角色是否"记起"了从未亲眼见过的事 |
| C2 | 角色一致性 | 行为是否符合人设（性格/能力/弱点） |
| C3 | 角色能力边界 | 角色做了一件能力做不到的事 |
| C4 | 角色关系变化 | 关系变化是否有铺垫和逻辑 |
| C5 | 角色视角限制 | 视角人物知道的信息是否超出范围 |
| C6 | 角色情绪弧线 | 情绪变化是否平滑、有迹可循 |
| C7 | 角色死亡合理性 | 角色死亡是否合理、是否需要更多铺垫 |
| C8 | 配角功能 | 配角是否只是工具人，有没有自己的性格 |

### 逻辑维度（Logic, 6个）

| # | 维度 | 检查内容 |
|---|------|---------|
| L1 | 因果逻辑 | 事件A是否必然导致事件B |
| L2 | 时间线矛盾 | 同一时间点出现两个矛盾的事件 |
| L3 | 动机缺失 | 角色做重要决定时是否交代了动机 |
| L4 | 资源守恒 | 物品/金钱/能力使用后是否减少/消耗 |
| L5 | 知识获取 | 角色获得某个信息是否有合理渠道 |
| L6 | 物理规则 | 世界观内的物理规则是否被打破 |

### 叙事维度（Narrative, 7个）

| # | 维度 | 检查内容 |
|---|------|---------|
| N1 | 伏笔未回收 | 铺垫过的钩子是否有回收 |
| N2 | 伏笔铺垫不足 | 回收伏笔时是否提供了足够线索 |
| N3 | 悬念维持 | 悬念是否在合适时机释放 |
| N4 | 信息节奏 | 重要信息是否在合适时机披露 |
| N5 | 支线游离 | 支线是否与主线有足够关联 |
| N6 | 章节结尾钩子 | 每章结尾是否有吸引人继续读的钩子 |
| N7 | 冗余描写 | 是否有对情节毫无推进的冗余段落 |

### 文风维度（Style, 6个）

| # | 维度 | 检查内容 |
|---|------|---------|
| S1 | AI痕迹 | 高频词、句式单调、过度总结 |
| S2 | 对话自然度 | 对话是否像真人说话 |
| S3 | 描写具体性 | 是否用具体细节代替抽象描述 |
| S4 | 句式变化 | 长短句是否有变化 |
| S5 | 感官层次 | 是否有多感官的描写（视觉/听觉/嗅觉/触觉） |
| S6 | 语言风格一致性 | 是否符合当前题材的风格要求 |

### 结构维度（Structure, 6个）

| # | 维度 | 检查内容 |
|---|------|---------|
| ST1 | 节奏分布 | 章节内紧张/平缓段落是否合理分布 |
| ST2 | 章节目标达成 | 本章是否完成了设定的写作目标 |
| ST3 | 大纲偏离 | 是否严重偏离了预先设定的大纲 |
| ST4 | 字数治理 | 字数是否在允许范围内 |
| ST5 | 场景转换 | 场景转换是否平滑、是否交代了时间/地点变化 |
| ST6 | 段落长度 | 是否有超长段落影响阅读体验 |

## 使用方式

```python
from auditor_33dim import Auditor33Dim

auditor = Auditor33Dim()

# 审计一章
result = auditor.audit(
    text=chapter_text,
    chapter_num=5,
    truth_files_dir="story/truth_files/",
    genre="xuanhuan"
)

# 获取评分
print(f"综合评分: {result.total_score}/100")

# 按维度查看问题
for dim, issues in result.issues_by_dimension.items():
    if issues:
        print(f"\n【{dim}】发现 {len(issues)} 个问题")
        for issue in issues:
            print(f"  [{issue.severity}] {issue.title}")
            print(f"    位置: {issue.location}")
            print(f"    建议: {issue.suggestion}")

# 打印摘要
auditor.print_summary(result)
```

## 评分权重

不同题材可以调整权重。例如：

| 题材 | 权重调整 |
|------|---------|
| 玄幻 | 逻辑维度权重+20%（升级体系要严密） |
| 都市 | 角色维度权重+20%（人设是核心） |
| 仙侠 | 叙事维度权重+20%（意境和节奏更重要） |
| 科幻 | 逻辑维度权重+30%（科学设定不能出错） |
