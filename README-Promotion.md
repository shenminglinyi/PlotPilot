# PlotPilot (墨枢) —— 开启长篇创作的智能纪元

## 一、 项目总览

PlotPilot（墨枢）不仅仅是一个简单的“聊天式写作助手”，而是一个专为**长篇连载、剧本创作以及复杂世界观构建**打造的**开源叙事引擎内核**。

在传统的 AI 辅助写作中，创作者经常会遇到一个痛点：当故事越写越长时，AI 往往会“失忆”——它会忘记早期设定的人物性格、弄错故事的因果逻辑，甚至遗漏之前埋下的伏笔。

PlotPilot 的诞生正是为了解决这个挑战。它将创作过程系统化，通过在后台默默管理一整套“故事状态”，让 AI 能够在一个清晰、连贯的框架内发挥它的生成专长。你只需要专注于灵感与方向，PlotPilot 则作为你最可靠的副驾驶，负责维持整个故事宇宙的逻辑一致性，让数十万字的长篇创作变得轻松而严谨。

---

## 二、 核心功能详解

### 1. 记忆永驻：全局叙事状态管理
PlotPilot 拥有一个强大的后台记忆库，能够实时捕捉并记录你故事中的每一个关键元素。无论是人物的性格档案、错综复杂的人物关系，还是故事发生地点的设定，它都能牢牢记住。在推进剧情时，它会自动参照这些设定，确保角色行为不崩坏，故事逻辑始终如一。

### 2. 智能提取：精准的上下文调度
在创作新章节时，你不再需要手动将之前的内容复制粘贴给 AI。引擎会自动分析当前的剧情走向，并从海量的历史章节中提取出最相关的背景、伏笔和关系线。这种“自动按需提取”的机制，彻底告别了 AI 的“金鱼记忆”，让新旧剧情无缝衔接。

### 3. 自动驾驶：流畅的创作流水线
如果你已经规划好了大纲，PlotPilot 可以开启“自动驾驶”模式。它能够按照“宏观分卷 -> 具体章节规划 -> 自动撰写”的步骤自动推进。在此过程中，它也保留了人工干预的节点，你可以随时在关键剧情处喊停，进行审阅、修改或重写，实现人机协作的完美平衡。

### 4. 百变声线：高度可定制的创作风格
不论你是在写言情小说、科幻巨作还是专业的影视剧本，PlotPilot 都能适应。它内置了高度灵活的策略配置系统，允许你针对不同的创作阶段（如大纲规划、正文撰写、风格润色）应用不同的规则和语气。切换一种创作风格，只需简单更换一套配置包，无需更改核心代码。

### 5. 品控护航：实时的质量监控与诊断
为了保证成文质量，PlotPilot 配备了自动化的质量监控系统。在每一章生成后，它会自动评估文本的情节张力和文风连贯性。如果发现某段剧情太平淡，或者行文风格偏离了你的初衷，系统会自动发出提醒，甚至建议进行局部重写。这就像为你配备了一位专业的“审稿编辑”，时刻把控作品的最终质量。
