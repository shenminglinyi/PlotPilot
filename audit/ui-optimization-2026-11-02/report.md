# PlotPilot 暗色工作台单屏审查

## 审查范围

- 截图：`01-dark-workbench.png`
- 页面：暗色主题、全托管驾驶舱、三栏工作区，重点审查红框标出的“写作支撑”右侧面板。
- 用户目标：在不牺牲信息量的前提下，让内部工作台更易扫读、更高效、更精致。

## Step 1：全托管驾驶舱

健康度：可用，但右侧高密度区域需要第二轮结构性精修。

### 优点

- 三栏职责明确：章节树、核心驾驶舱、写作支撑。
- 暗色表面、卡片边界和状态色已经形成统一语言。
- 关键状态大多同时使用文字和颜色，不完全依赖颜色表达。

### 主要风险

1. **P1 · 进度指标互相矛盾**
   - 顶栏显示完成率 `0.9%`，驾驶舱显示全书进度 `10.6%`。
   - 同屏核心指标不一致会直接削弱用户对自动驾驶状态的信任。
   - 建议先统一指标定义、分母和文案；若一个是章节完成率、一个是字数进度，必须在标签中说明。

2. **P1 · 右侧面板所有模块几乎同权**
   - 叙事简报、活跃线体、未兑现承诺、角色当下、引擎记忆都使用相近边框和标题强度。
   - 用户无法快速判断“现在需要处理什么”。
   - 建议建立三级层级：当前阶段/风险为一级，待处理承诺为二级，角色和记忆为参考级。

3. **P2 · 两层导航竞争注意力**
   - “写作支撑 / 作品基础”与下方“叙事简报 / 当前语境 / 伏笔账本 / 故事演进”同时横向排列，选中态差异偏弱。
   - 建议把上层做成明确的分区切换器，下层做成带底线的局部标签；两层使用不同高度、底色和选中反馈。

4. **P2 · 信息密度过高，扫读路径不稳定**
   - 未兑现承诺使用长句列表，角色区连续重复同类图标，英文 `growth` 与中文标签混排。
   - 建议保留内容但改成固定列：类型 / 标题或承诺 / 状态；长句默认两行截断，悬停或展开查看全文。

5. **P2 · 中央留白与右侧拥挤形成失衡**
   - 中央主要卡片以下是大面积空画布，右侧却需要持续纵向滚动。
   - 在“不改三栏布局”的前提下，可让右侧模块支持紧凑/舒展密度切换，并把低优先级区默认折叠；中央空白保持为工作区，不建议再堆装饰。

### 可访问性风险

- 右侧说明文字和顶层次级标签对比度偏低，字号也接近可读下限；建议正文至少 12.5–13px、行高 1.5，弱文本仍需满足暗色背景可辨识度。
- 多个横向标签与小按钮点击区域偏矮，建议可点击高度至少 32px，主要操作达到 36px。
- 仅凭截图无法确认键盘顺序、焦点环、屏幕阅读器标签和 200% 缩放表现，需要浏览器交互测试。

## 推荐执行顺序

1. 先统一 `0.9% / 10.6%` 的业务口径与标签。
2. 重做右侧模块层级和双层导航选中态，不改变栏宽和内容。
3. 统一列表行模型、图标、标签语言与长文本截断。
4. 提升暗色小字对比度、点击热区和滚动定位反馈。
5. 最后再微调边框、阴影与圆角，避免继续增加无意义的视觉层。

## 证据限制

- 本次只审查用户提供的单张稳定截图，没有操作真实页面。
- 无法从截图确认 hover、focus、折叠、加载、空状态、错误状态和键盘行为。
